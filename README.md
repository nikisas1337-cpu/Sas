# Hello World Notification

Проста Android-програма: на екрані є кнопка, при натисканні якої з'являється сповіщення з текстом **Hello World!**

## Як запустити

1. Відкрийте теку проєкту в Android Studio.
2. Дочекайтеся синхронізації Gradle.
3. Запустіть застосунок на емуляторі або телефоні (Android 7.0+).
4. Натисніть кнопку **«Надіслати сповіщення»**. На Android 13+ спершу дозвольте показ сповіщень.

Збірка з командного рядка: `./gradlew assembleDebug` (APK буде в `app/build/outputs/apk/debug/`).
