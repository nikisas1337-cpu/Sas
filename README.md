# Hello World Notification

Проста Android-програма: на екрані є кнопка, при натисканні якої з'являється сповіщення з текстом **Hello World!**

## Як запустити

1. Відкрийте теку проєкту в Android Studio.
2. Дочекайтеся синхронізації Gradle.
3. Запустіть застосунок на емуляторі або телефоні (Android 7.0+).
4. Натисніть кнопку **«Надіслати сповіщення»**. На Android 13+ спершу дозвольте показ сповіщень.

Збірка з командного рядка: `./gradlew assembleDebug` (APK буде в `app/build/outputs/apk/debug/`).

# Батарея Оверлей (модуль `batteryoverlay`)

Android-програма, яка **поверх усіх застосунків** у реальному часі показує два незалежні написи:

1. **Споживання зараз** — миттєва потужність у ватах і струм у мА (`⚡ 2,41 Вт · 612 мА`).
   Під час заряджання показує потужність, що йде в батарею (`🔌 +5,20 Вт`).
2. **Розрахунковий час роботи** — точний час (год / хв / с), скільки телефон проживе при поточному
   енергоспоживанні, і годинник, коли він вимкнеться (`⏳ 5 год 23 хв 10 с · до 03:45:12 (64%)`).
   Під час заряджання — час до 100 %.

Розрахунок: `заряд, що залишився (мкА·год) ÷ поточний струм (мкА)`. Струм оновлюється щосекунди
й трохи згладжується, щоб час не стрибав від кожного короткого піку.

## Налаштування — окремо для кожного напису

- **Переміщення** — перетягніть напис пальцем у будь-яке місце екрана.
- **Збільшити / зменшити** — щипок двома пальцями (або повзунок «Розмір тексту»).
- **Розтягнути** — щипок горизонтально розтягує по ширині, вертикально — по висоті
  (або повзунки «Розтягнути по ширині / висоті»).
- **Колір тексту і фону** — палітра: готові кольори + повзунки відтінку, насиченості, яскравості
  та прозорості фону.
- **Довгий дотик** по напису (або кнопка «Редагувати на екрані») — повноекранний режим
  редагування: жести працюють будь-де на екрані, навіть якщо текст дуже маленький.
- **Подвійний дотик** — відкрити налаштування.
- **Заблокувати написи** — дотики проходять крізь них до застосунків під ними.

## Встановлення

APK збирається GitHub Actions і публікується в релізі `battery-overlay-apk`
(файл `BatteryOverlay.apk`). Після встановлення відкрийте програму, надайте дозвіл
«Показ поверх інших застосунків» і натисніть **«Запустити оверлей»**.

Збірка локально: `./gradlew :batteryoverlay:assembleDebug`.

> Деякі телефони не повідомляють струм батареї (тоді буде `—`) або оновлюють його рідко —
> це обмеження конкретного пристрою.
