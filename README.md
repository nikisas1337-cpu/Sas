# Hello World Notification

Проста Android-програма: на екрані є кнопка, при натисканні якої з'являється сповіщення з текстом **Hello World!**

## Як запустити

1. Відкрийте теку проєкту в Android Studio.
2. Дочекайтеся синхронізації Gradle.
3. Запустіть застосунок на емуляторі або телефоні (Android 7.0+).
4. Натисніть кнопку **«Надіслати сповіщення»**. На Android 13+ спершу дозвольте показ сповіщень.

Збірка з командного рядка: `./gradlew assembleDebug` (APK буде в `app/build/outputs/apk/debug/`).

# LTE Boost (модуль `boost`)

Кнопка **«4G MAX»** у шторці швидких налаштувань. Одне натискання вмикає режим «максимум», друге повертає все як було.

Що робить режим:
- дозволяє лише LTE (з агрегацією несучих), щоб телефон не скидався на 3G/2G і не стрибав на слабке 5G;
- вимикає Wi-Fi, щоб увесь трафік ішов через 4G (можна вимкнути в налаштуваннях);
- вимикає енергозбереження, яке обмежує фонові дані (можна вимкнути в налаштуваннях).

На головному екрані видно поточний сигнал (RSRP, RSRQ, SINR), діапазон (band), ширину смуги, агрегацію несучих і швидкість мобільного інтернету.

Root не потрібен, але потрібен [Shizuku](https://shizuku.rikka.app/): він дає застосунку права ADB. Запускається один раз після кожного перезавантаження через «Бездротове налагодження», без комп'ютера.

Збірка: `./gradlew :boost:assembleDebug`. Готовий APK GitHub Actions публікує в релізі `lte-boost-apk`.
